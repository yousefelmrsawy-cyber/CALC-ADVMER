# Advanced Web Calculator

A responsive, feature-rich web calculator built with HTML, CSS, and Vanilla JavaScript.

## ✨ Features

- **Standard Arithmetic Operations**: Addition, subtraction, multiplication, and division with operator precedence.
- **Mathematical Constants**: Built-in support for Pi ($\pi$).
- **Theme Toggle**: Animated Light/Dark mode switch with morphing Sun (☀️) and Moon (🌙) icons.
- **Keyboard Support**: Full keyboard input support (Numbers, Enter for `=`, Backspace for `del`, Escape for `RESET`, `P` for `π`).
- **Persistent Theme**: Remembers your preferred mode (Light or Dark) using `localStorage`.

- **HTML5**
- **CSS3** (Flexbox, CSS Transitions, Custom Theme Variables)
- **Vanilla JavaScript** (ES6+)
